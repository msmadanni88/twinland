# کتابخانه تصویر رویدادها

هر فایل اینجا با نام کلید تصویر ذخیره می‌شود، مثلا `cup.png`.
اندازه پیشنهادی 256 در 256، پس‌زمینه شفاف، PNG یا SVG.
بعد از گذاشتن فایل، کلید را به آرایه `REAL_ART` در `lib/events/art.js` اضافه کن. جای دیگری عوض نمی‌شود.
کلیدها: cup latte teapot bean croissant cake cookie icecream burger tag gift ticket key party music book palette gamepad moon star heart trophy crown gem flame leaf clock pin
